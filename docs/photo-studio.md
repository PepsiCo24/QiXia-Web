# 栖小猫 · 栖霞留影

## 使用

地图下方「开始留影」进入 `/photo`，也可直接访问该路由。选相框后主动开启摄像头（只请求视频），或上传本机照片。拍摄为 3 秒倒计时，可取消；有多个视频输入设备时显示切换镜头。拍摄完成立即停止视频流。

编辑中可切换相框、拖动或用左右/上下滑块调整位置、缩放、使用自然滤镜（原色/提亮/柔和/暖色与强度），可对照原图色调、一键还原、重拍。生成 1200×1600 JPEG 后下载；支持文件分享的系统显示原生分享。手机可长按结果图片保存。返回编辑可重新生成。

摄像头要求 HTTPS 或 localhost；局域网 HTTP 地址一般不支持摄像头，仍可上传。拒绝授权、无设备、占用、不兼容均有备用入口。浏览器原生授权弹窗仍需游客亲自操作。

## 架构

- `app/photo/page.tsx`：静态可预渲染独立页面与元信息。
- `components/qixia/photo/photo-entry.tsx`：地图模块之后的独立入口，不改地图内部逻辑。
- `components/qixia/photo/photo-studio.tsx`：引导 → 授权/取景 → 倒计时 → 编辑 → 生成 → 保存状态与资源生命周期。
- `components/qixia/photo/use-camera.ts`：视频授权、切换、错误、取消/迟到流停止。
- `lib/photo/frames.ts`：四款相框配置。
- `lib/photo/render.ts`：共享 Canvas 渲染、裁切/镜像、逐像素自然滤镜与纪念文字；600×800 预览与 1200×1600 导出使用同一 1200×1600 设计坐标。照片区域为上部 1200×1380，下部专用于文字/日期/灵猫，保证不压住面部。自然滤镜不依赖 CSS 或 Canvas filter 支持，不做人脸识别与五官变形。
- `lib/photo/collection.ts`：默认关闭的后续真实领取服务接口，不发起网络上传，不生成二维码。

拍摄源最长边 2048，上传缩放至最长边 2400。上传上限 20MB、解码后上限 5000 万像素；超大照片的解码瞬时开销仍取决于浏览器，低内存公共设备建议限定源图片尺寸。滤镜按64行条带处理，限制临时ImageData内存。

## 素材与后续替换

仅复用仓库现有 `public/pet/qixia-cat/frames/wave-0.png`，没有引入第三方猫咪或景区图片，也不将新画的通用猫作为正式 IP。该素材沿用现站资产，正式线下商用仍应由项目方确认现有 IP 授权。

相框的山线、枫叶、爪印、邮笺线为程序绘制的原创可替换设计稿，界面及导出页脚均标有「设计草案」。主题为「栖小猫来合影」「栖霞枫叶季」「山间来信」「灵猫专属纪念」。品牌纪念款结合现有灵猫、山月与网站配色，不会偷偷读取游客身份或聊天记录。正式素材可在相框配置与 drawFrame 中替换，必须保留相同设计坐标/安全区，并使用同源资产，兼容 NEXT_PUBLIC_BASE_PATH。

专业人脸美颜没有接入。目前准确标注为自然滤镜，只改变全图色调。若后续接 SDK，应另行评估授权、隐私、本地推理与低端设备性能。

## 公共大屏隐私

点击「景区大屏模式」切换大触控按钮；切换本身会结束上次会话。120 秒无操作自动清空照片、结果 Blob 引用与对象 URL、关闭摄像头、复位相框/滤镜并返回引导。结束按钮、离开路由、pagehide、页面切后台均执行清理，避免上一位游客照片遗留。生成或授权中发生清理，迟到结果通过会话代数丢弃，迟到摄像头流也会立即停止。

不使用 localStorage/IndexedDB 存储照片，不上传照片。浏览器下载目录、操作系统分享文件属于游客主动保存的副本，页面无法撤回；公共设备运营应配置独立临时用户/下载目录到期清理，并优先在游客自有设备保存。

系统原生分享可能令页面切后台，因此页面会清空，而系统仍持有游客同意分享的文件。该行为在结果页明确说明。

## 真实扫码领取接入前置条件

当前无照片上传/存储后端，因此没有领取二维码。后续实现 PhotoCollectionService 时必须同时提供：

1. 上传前明确说明用途/保留时间并取得单独同意（接口要求 consent.granted 与时间）。
2. 临时对象存储、不可猜测的高熵领取凭证、TLS、访问限制与速率限制；不要用游客ID或顺序编号。
3. 真正可访问的领取页面、有效期提示、到期拒绝与存储生命周期/后台删除任务。
4. 清理与撤销接口、上传取消、失败重试，且不要把凭证写入分析日志。
5. 仅后端成功返回真实 claimUrl 后生成二维码；静态 GitHub Pages 本身不能提供这些服务。

## 验证

项目原有脚本只有 dev/build/start，没有单独 lint 脚本。执行 `pnpm build` 与 `pnpm exec tsc --noEmit`。回归测试：`pnpm exec playwright test tests/photo.spec.ts`，默认服务器 `http://127.0.0.1:3001`，可用 TEST_BASE_URL 覆盖。

自动测试使用合成 Canvas 视频流与模拟错误，不触发真实用户摄像头；覆盖主动授权且 audio:false、权限拒绝/无设备/占用、切换、倒计时取消/完成、前置镜像、重拍关闭流、上传、四框切换、缩放/位移、滤镜与JPEG导出像素一致（允许JPEG误差）、原图与还原、下载、对象URL撤销、后台清理、迟到授权流回收、公共设备120秒超时、390×844/844×390/1920×1080无横向溢出，以及地图入口/返回链接。

仍需真机验收：iOS Safari/安卓浏览器的物理前后摄像头与原生授权UI、各系统相册与分享落地、实际景区触摸屏与低内存设备表现。本地模拟通过不代表这些真机流程已验证。此次不涉及线上发布或真实上传服务。
